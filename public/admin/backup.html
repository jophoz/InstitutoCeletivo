Backup

Leva o conteúdo de um site para outro (por exemplo, do seu computador para o site no ar) sem precisar de acesso ao servidor. Também serve como cópia de segurança.

Baixar backup

Baixa um arquivo com produtos, páginas de vendas, blocos salvos, empresas e imagens deste site.

Não entram: usuários do painel, contas da Kiwify (a chave secreta só funciona no servidor onde foi cadastrada), visitas e vendas do Resumo. Os textos fixos do site (Sobre, contato, redes) ficam no código e não entram.

Importar backup

Envia um arquivo de backup para este site. O que já existe com o mesmo item é atualizado; o que existe só aqui não é apagado. Importar o mesmo arquivo de novo não duplica nada.

Os dois sites precisam estar na mesma versão. Depois de importar, conecte a Kiwify de novo em Empresas (se usar).
